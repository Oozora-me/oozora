# Conventions - Constructive Bidding

> 建设行叫牌。

## 雅各比2NT Jacoby 2NT

> https://www.bridgebum.com/jacoby_2nt.php

概要：
1. 开叫人：开叫1阶高花
2. 应叫人：应2NT。这是逼叫。表示应叫人13点以上，且4张以上的开叫花色支持。且有满贯想法。

后续开叫人再叫：
1. 示弱：开叫人再叫4阶开叫高花。
2. 3阶再叫开叫花色：6张所叫高花，无单缺，逼叫，中限以上，有满贯想法，可能为6322/7222牌型。
3. 3NT：有额外牌力，无单缺，可能是5422/5332牌型。
4. 3阶新花色：所叫为单缺，逼叫。
5. 4阶新花色：所叫为5张套，逼叫。

## 低花反加叫 Inverted Minors

> https://www.bridgebum.com/inverted_minors.php

概要：
1. 开叫人：开叫1阶低花
2. 应叫人：
  - 加叫2阶表示10点以上，草花4张以上支持（如果是10点，最好是5张），逼叫。
  - 加叫3阶表示0-6点，5张以上支持，可以起到一个狙击的作用。
  - 注意：
    - 如果有4张高花，一般还是一盖一先
    - 如果是7-9点牌怎么办，可以1NT的

后续开叫人再叫：
1. 2阶平叫花色基本都是自然叫：1C - 2C - 2D/2H/2D(4+)，逼叫。
  - 通常2H/2S都是4+，不然那就是均型牌可以2NT，如果交出2H/2S通常都是非均型
2. 2NT：12-14点均型牌，不逼叫。
3. 3阶开叫低花：自然叫（5+套），不逼叫，非均型牌，应叫人根据自己牌情选择pass/扣叫/进局。
4. 3D（开叫1C时）：有两种处理方式
  - 自然叫（建议）：5+方块套（最好是5+，不然可以再叫2D），逼叫。
  - 人工叫：我不知道3NT还是5C，等你确定，应叫人可以描述高花止张。
5. 3NT：一般是均型牌，18-19点
  - 为什么不是15-17呢，是因为15-17均型牌开叫1NT了
  - 思考一下：如果是6322也不是不可能？
6. 其它：
  - 3H/3S开始扣二轮以上控制
  - 4H/4S：Splinter，该花色单缺，低花很好的支持，逼叫。
  - 如果开叫1C，4C应该是不逼叫，我有额外牌力，但是我没有其它控制张。
  - 如果开叫1D，4C是Splinter，单缺，逼叫。
